# Implemented Features:

There are multiple features that work. The player's hand is randomly generated according to the JSON data structure and eventually runs out. The tiles are able to be drag and dropped underneath the actual board to allow the user to still see the board for the bonus squares which are working. The score is updated in real time and there is a running tally for total score. When submitted the word is cleared from the board and the user only draws the necessary letters from the tile bag. The user is only able to place the tiles in the scrabble board and the tile is bounced back to the rack if it is placed in a full slot, non-adjacent slot, or not on the board. When it is bounced back however, the animation no longer works so you can still drag it to the board it just doesn't have an animation to be placed on the board. There is also a reset button.
